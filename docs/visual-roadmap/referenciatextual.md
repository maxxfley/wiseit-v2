# Propuesta: Roadmap Interactivo de Aprendizaje

## 1. Concepto general

Implementar un roadmap visual e interactivo para cada temática de aprendizaje (por ejemplo, Astronomía, Psicología, Historia, Programación, etc.).

La idea es representar el conocimiento como un mapa de nodos conectados, donde cada nodo representa un tema, concepto o unidad de aprendizaje. El usuario puede recorrerlo, descubrir nuevos conceptos y registrar su propio progreso.

El objetivo es que la experiencia se sienta como explorar un mapa de conocimientos, no como utilizar una lista convencional de tareas.

## 2. Estructura visual

El roadmap debe estar compuesto por nodos distribuidos visualmente y conectados mediante líneas o caminos que representen relaciones de aprendizaje.

Cada nodo puede representar:
- Un tema principal.
- Un concepto específico.
- Una subcategoría.
- Una unidad de aprendizaje.
- Un tema avanzado que requiere conocimientos previos.

Los nodos pueden ramificarse. Por ejemplo:

Astronomía → Sistema Solar → Planetas → Planetas rocosos / Planetas gaseosos.

Esto permite construir recorridos de aprendizaje progresivos y visualmente atractivos.

## 3. Estados de los nodos

Cada nodo debe tener diferentes estados visuales, que permitan identificar rápidamente el progreso del usuario.

| Estado | Representación visual | Descripción |
|---|---|---|
| Disponible | Contorno tenue | El usuario puede comenzar a estudiarlo. |
| En proceso | Azul | El usuario comenzó a estudiar el contenido, pero todavía no lo completó. |
| Completado | Verde | El usuario terminó el contenido. |
| Bloqueado | Gris | Requiere completar conocimientos previos. |

Los estados deben distinguirse mediante colores, indicadores e iconografía, sin depender exclusivamente del color.

## 4. Interacción con los nodos

Al seleccionar un nodo, debe desplegarse un panel de información contextual, preferentemente lateral o flotante.

Este panel debe mostrar:

- Nombre del tema.
- Descripción breve.
- Estado actual.
- Porcentaje de progreso.
- Contenidos o subtemas relacionados.
- Recursos disponibles.
- Acción para comenzar o continuar estudiando.
- Opción para marcar como completado.

Por ejemplo, al seleccionar «Planetas y Enanos», el panel puede mostrar sus diferentes unidades:

- Tipos de planetas.
- Planetas enanos.
- Órbitas y movimientos.
- Atmósferas planetarias.

Cada unidad también puede tener su propio estado de progreso.

## 5. Comportamiento dinámico

El roadmap debe actualizarse visualmente según las acciones del usuario.

Ejemplos:

- Al comenzar un tema, su nodo cambia a azul.
- Al completar un tema, cambia a verde y muestra un indicador de finalización.
- Al completar los requisitos de un tema bloqueado, este pasa a estar disponible.
- Al seleccionar otro nodo, el panel contextual actualiza su información.
- Las conexiones entre nodos pueden cambiar de apariencia para representar el avance del usuario.

## 6. Diseño y experiencia visual

La estética debe ser moderna, atractiva y tecnológica.

Se propone:

- Fondo oscuro con profundidad visual.
- Nodos con bordes redondeados.
- Líneas curvas que conecten los diferentes conceptos.
- Efectos sutiles de iluminación y resplandor.
- Transiciones suaves al seleccionar nodos o cambiar estados.
- Indicadores visuales de progreso.
- Distribución orgánica de los nodos, evitando una estructura rígida de lista.

La temática visual puede adaptarse al contenido. Por ejemplo, Astronomía podría utilizar una estética espacial, mientras que Historia podría utilizar una representación visual diferente.

## 7. Objetivo final

Crear una experiencia de aprendizaje visual donde cada usuario pueda observar cómo evoluciona su conocimiento, identificar qué temas ya domina, cuáles está estudiando y cuáles todavía tiene pendientes.

El roadmap debe funcionar como una representación visual del recorrido de aprendizaje de cada persona, permitiendo explorar conocimientos, establecer conexiones entre conceptos y visualizar el progreso de manera intuitiva.
